Maintained-continuation release of GTMOGS for Project Commonwealth (theasshats/gtmogs, branch `pcmc/main`). LGPL-3.0-only; complete corresponding source is this repository at the release tag.

## New

- `/gtmogs census` (permission level 2): aggregates the current dimension's persisted placed-vein records — the same data prospecting reads — into per-vein counts (sorted, with depleted tallies when present). Replaces the debug.log grepping in the pack's ore-calibration loop (theasshats/project-commonwealth#318 §F).
- Internal: `WorldCache`/`DimensionCache` gain a `getAllVeins` accessor to back the command.

## Repository (not in the jar)

- `docs/VEIN-MATH.md` + `tools/vein_yield.py` — exact yield math for the classic vein generator (Monte-Carlo validated).
- `tools/member_diff.py` + a weekly CI tripwire that verifies the release jar's Xaero references against the newest World Map / Minimap builds on Modrinth and files an issue on drift.

## Carried from 1.0.6-pcmc.1

The Xaero's World Map 1.40+ compatibility fix (both map integrations decoupled from the removed `ModSettings` waypoint fields).

## Verification

- Member-level reference check against Xaero's World Map 1.41.0 + Minimap 26.1.0: clean (re-verified by this release's build workflow against the newest builds at release time).
